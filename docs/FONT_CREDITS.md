# 글꼴 출처

| 용도 | 한글 글꼴 | 비고 |
| --- | --- | --- |
| 게임 글꼴(한글 919자) | 나눔스퀘어네오 Bd (`NanumSquareNeo-cBd.ttf`) | 20픽셀 칸으로 512×512 텍스처 두 장에 그려 넣습니다. |

글꼴 파일은 저장소에 포함하지 않습니다. 게임에 들어가는 것은 글자를 비트맵으로 그린 결과뿐입니다.

재빌드하려면 `docs/BUILD.md`에 적은 글꼴 파일을 저장소 최상위나 `fonts/` 폴더에 두세요.
