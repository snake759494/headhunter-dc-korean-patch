# 기술 설명

유럽판 헤드헌터(디스크 1·2, Redump cue/bin)를 해석한 내용입니다.

## 디스크 구성

- GD-ROM의 고밀도 영역인 Track 3(LBA 45000부터)가 ISO9660 파일 시스템입니다. 패치는 이 트랙만 고칩니다(`gdfs.py`).
- 게임 데이터는 대부분 `AHFDATA/*.AHF` 묶음 파일 안에 들어 있습니다. 스테이지마다 AHF가 하나씩 있고, 공통 데이터는 `HEADHUNTER.AHF`에 있습니다.
- 섹터를 고칠 때마다 Mode 1 섹터의 EDC/ECC를 다시 계산합니다. 원래 자리에 들어가지 않는 파일은 트랙 뒤쪽 빈 영역으로 옮기고 디렉터리 레코드의 위치·크기를 고칩니다(`gdfs.put`).

| 데이터 | 위치 | 처리 |
| --- | --- | --- |
| 텍스트(CSV/TXT) | AHF 안 `HEADHUNTER\LOCALE\...` | `kotext.py` |
| 실행 파일 | `1ST_READ.BIN` | `patch_exe.py` |
| 한글 글꼴 텍스처 | `HEADHUNTER.AHF`에 `KOR0.PVR`, `KOR1.PVR` 추가 | `kfont.py` |
| 그림 글자 | AHF 안 `*_GERMAN.PVR`, `TITLE_LOCALTEXT`, `TOP_TEXT.PVR`, `HUD_RADAR_TEXT.PVR` | `title_tex.py`, `loc_tex.py` |

## AHF 형식

`'AHFF'`, 버전, 항목 수, 헤더 끝 위치가 앞에 있고, 항목마다 (오프셋, 크기, 알 수 없는 값, 0으로 끝나는 이름)이 4바이트 정렬로 이어집니다. 데이터는 8바이트 단위로 정렬됩니다(`ahf.py`).

- 원본은 같은 내용의 항목도 따로 저장합니다. 게임이 항목을 제자리에서 처리하므로 다시 만들 때도 데이터를 공유시키면 안 됩니다.
- 파일 끝의 줄바꿈 등 원본의 바이트 구조를 바꾸면 스테이지를 불러올 때 멈추므로 그대로 유지합니다.

## 텍스트

- 언어별로 `LOCALE\<언어>\` 폴더(TXT)나 CSV의 언어 열에 문장이 들어 있습니다. 인코딩은 cp1252입니다.
- **CSV**: `;`로 구분하며, 첫 열은 키, 그 뒤가 언어별 문장입니다. 일부 파일은 줄 전체가 따옴표로 둘러싸여 있습니다(`segs.QUOTED_CSV`).
- **TXT**: 종류에 따라 나눠 처리합니다(`segs.kind`).
  - 자막(`SUBTITLE\*`): `;시각;` 접두어 뒤의 여러 줄 문장
  - 문서·임무 목표: 문단 단위로 묶어 번역한 뒤 원래 폭에 맞춰 다시 줄을 나눔
  - 그 밖의 TXT: 줄 단위
- 번역은 `tr/*.json`에 `{"h": 원문 SHA-1 앞 16자리, "ko": 한국어}`로 저장했습니다. 같은 문장은 파일이 달라도 번역을 함께 씁니다.
- 줄 폭은 게임 글꼴의 글자 폭 표(`fonts.json`)로 계산합니다. 한글은 글자 칸 폭의 고정 비율로 계산합니다.
- 스크립트가 장소 이름을 키로 찾는데 CSV에 그 줄이 없는 스테이지(부두, 노스 지구)는 CSV 끝에 한국어 줄을 덧붙입니다(`kotext.EXTRA`). 지도 데이터 안의 이름을 직접 바꾸면 스테이지가 멈춥니다.

## 한글 표시

- 게임 글꼴은 1바이트 문자만 다룹니다. 실행 파일의 글자 그리기 루틴 다섯 곳(`patch_exe.SITES`)에 분기를 넣어 2바이트 한글을 처리하게 했습니다.
  - 첫 바이트 0x80–0x9F, 둘째 바이트 0x80–0x9F 또는 0xE0–0xFD를 한 글자로 봅니다. 글자 번호는 `첫 바이트×62+둘째 바이트`로 정합니다(`kfont.code`).
  - 이 범위의 cp1252 문자는 번역문에 쓰지 않습니다.
- 추가 코드는 실행 파일 안의 쓰이지 않는 영역(0x8C0E7F84–0x8C0E83E4)에 SH-4 어셈블리로 넣습니다(`sh4asm.py`). 글꼴 텍스처를 만들 때 `KOR0`·`KOR1` 텍스처도 함께 불러오도록 텍스처 생성 호출을 바꿨습니다.
- 한글 글리프는 번역문에 쓰인 글자를 빈도순으로 정렬해 20픽셀 칸에 그리고, 512×512 ARGB4444 VQ 텍스처 두 장으로 만듭니다(`kfont.py`).
- **언어 고정:** 언어 번호를 독일어 칸(1)으로 고정하고 이 값을 바꾸는 코드를 더미 주소로 돌렸습니다. 한국어는 독일어 칸과 `_GERMAN` 그림에 넣습니다. 그래서 언어 설정과 관계없이 한국어가 나옵니다.

## 그림 글자

- PVR 텍스처는 대부분 VQ 압축(256개 2×2 코드북 + 트위들된 색인)입니다. 이 게임에서는 형식 번호 5·6도 실제로는 ARGB1555 VQ입니다(`title_tex.FMAP`).
- 텍스처를 RGBA로 풀어 원래 글자를 지우고 한국어를 그린 뒤, k-평균으로 코드북을 다시 만들어 같은 형식·크기로 인코딩합니다.
- 작업 목록(`loc_tex.py`):
  - 버튼(`YESNO_GERMAN`, `CANCEL_GERMAN`): 밝은 테두리 줄로 칸을 찾고, 칸 배경을 위아래로 보간해 글자를 지운 뒤 원래 색으로 씁니다.
  - 50/60Hz 안내(`HZ_TXT_GERMAN`): 화면의 한 줄이 텍스처의 16픽셀 줄 두 개(i, i+5)로 나뉘어 있어 그 순서대로 단어를 채웁니다.
  - 메뉴 탭(`TOP_TEXT`): 왼쪽은 선택된 빛나는 글씨, 오른쪽은 얇은 글씨입니다.
  - 레이더 경고(`HUD_RADAR_TEXT`): 화면의 한 단어가 16픽셀 줄 두 개(DANG|ER, WARN|ING)에 나뉘어 있어 한국어도 같은 폭으로 나눠 그립니다.
- 타이틀 문구(`TITLE_LOCALTEXT`)는 `title_tex.py`가 처리합니다.
